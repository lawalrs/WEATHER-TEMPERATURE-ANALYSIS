# WEATHER-TEMPERATURE-ANALYSIS
Findings
Observation 1
The temperature data shows that Lagos recorded the highest temperature on Days 1, 2, and 3, while Abuja recorded the highest temperature on Days 4 and 5.

Observation 2
When every temperature is increased by 1°C, NumPy applies the calculation to all values in the arrays at once. This demonstrates the usefulness of vectorized operations.

Observation 3
The Lagos and Abuja comparison shows that Lagos was warmer than Abuja on Days 1, 2, and 3. However, Abuja was warmer than Lagos on Days 4 and 5.

Observation 4
Abuja recorded the highest individual temperature in the dataset, with 32.0°C on Day 5.

Observation 5
NumPy makes it easier to work with larger numerical datasets because mathematical operations can be performed on entire arrays without manually processing every value.

Conclusion
This project demonstrated how NumPy can be used to analyze temperature data from multiple locations.

The analysis involved creating NumPy arrays, inspecting their dimensions and data types, performing calculations, increasing temperatures by 1°C, and comparing Lagos and Abuja temperatures.

The results show that NumPy provides a convenient way to perform numerical calculations on multiple values simultaneously. As the amount of numerical data increases, using NumPy arrays becomes increasingly useful for efficient analysis and comparison.
